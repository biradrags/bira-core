# AGENTS.md — правила разработки bira-core для AI-агентов

`bira-core` — публичная Python-библиотека (library, not framework): узкие фасады,
готовые Dispatcher/Bot/Container принимает потребитель, либа не владеет жизненным циклом.

`CLAUDE.md` — симлинк на `./AGENTS.md`. Локальные `.claude/rules/` не заводить.

## Устав

- Protocol на границах, DTO-only сигнатуры; ABC только с готовой общей реализацией.
- Без миксинов; композиция списками (`register(...)`), не наследование-с-переопределением.
- Явный `__all__` в `bira_core/__init__.py`; `tests/test_public_api.py` пинит поверхность.
- Rule-of-three: новая точка расширения — только при втором реальном потребителе.

## Харвест

Модуль рождается из файла-донора с построчной сверкой. Расхождение с эскизом → донор
выигрывает либо адаптация в `CHANGELOG.md`. См. `CONTRIBUTING.md` (теги, deprecation).

## Тесты

- BaseDAO — интеграционные тесты против реального Postgres, не SQLite.
- Фикстуры — только синтетические значения; секреты не читать и не печатать.
- Коммиты без AI-атрибуции (`Co-Authored-By`, «Generated with…»).

## Публичная гигиена

Никаких имён клиентов, внутренних хостов, инцидент-деталей в коде, комментариях,
фикстурах и публичной документации.

## Команды

```bash
make install   # uv sync --all-extras
make check     # lint + typecheck + test
```
